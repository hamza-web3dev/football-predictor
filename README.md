# ⚽ Match Predictor

An AI-powered football match prediction app built with **Streamlit**, **Flask**, and **CatBoost**.

The app allows users to:

- Select teams and formations
- Build custom lineups
- Visualize players on a live football pitch
- Generate match outcome predictions using a trained ML model

---

## 🚀 Features

- Interactive Streamlit UI
- Live tactical pitch visualization
- Formation & lineup builder
- Historical team statistics
- Player performance analysis
- CatBoost match prediction API
- Win / Draw / Loss probabilities

---
